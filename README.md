# HeliumWiki

This repository contains a knowledge database for agentic helium optimization and an agentic flow to extend this knowledge base.

The folder `helium-wiki` is the self contained Helium optimization skill and knowledge base.

The files outside of `helium-wiki`, like the `scripts`, are used to extend the knowledge base.

The scripts inside `helium-wiki` are used by the skill to navigate the knowledge base.
